# MultiMC Installer

A basic installer for the popular Minecraft instance manager MultiMC. https://multimc.org/

## Download
*win64 is the only supported platform right now*

#### [Latest Release](https://github.com/modpotato/MultiMC-Installer/releases/download/Release/MultiMCInstaller.exe)

## Setup Guide

1. Download the installer from the link above.
2. Run the installer executable.
3. Follow the on-screen instructions to complete the installation process.
4. Once installed, launch MultiMC from your Start menu or desktop shortcut.
